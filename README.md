
# CLI Quiz Game 🎯

## About the Project

CLI Quiz Game is an interactive command-line application
built with Python. It allows users to answer multiple-choice
questions, receive instant feedback, and get a final score
based on their performance.

## Features

- Multiple-choice questions (A, B, C, D).
- Randomized question order.
- Automatic score calculation.
- Instant feedback on answers.
- Final performance evaluation.
- Input validation.

## Technologies Used

- Python 3
- Random module

## How to Run the Application

1. Clone this repository:

   git clone https://github.com/mathekasarah-prog/CLI_Quiz_Game_App.git

2. Navigate to the project folder:

   cd CLI_Quiz_Game

3. Run the application:

   python quiz_game.py

## How to Play

1. Run the application in your terminal.
2. Read each question carefully.
3. Select your answer using A, B, C, or D.
4. Receive instant feedback.
5. View your final score at the end.
